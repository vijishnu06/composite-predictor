# Honest CV description

Built a Python/Streamlit prototype for defect-aware tensile-strength estimation in nominal UD E-glass/epoxy composites.
Generated reproducible simulated data from a documented micromechanics model and compared Linear Regression with Random Forest using holdout and extrapolation tests.
Implemented provenance checks, model persistence, scenario/sensitivity views, and a separate literature-comparison workflow.
Simulation-based educational project; no experimental validation claimed.
