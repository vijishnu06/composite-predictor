# Methodology

1. Define a nominal unidirectional E-glass/epoxy simulator, not an experimental ground truth. Fibre volume fraction is entered in percent and divided by 100 inside the mixture model; void content remains in percentage points in exponential knock-downs. Angle is measured between fibres and tensile loading.
2. Independently sample 2,000 uniform points in Vf 20–65%, void 0–8%, angle 0–45°. Add zero-mean Gaussian multiplicative scatter of standard deviation 0.05 with seed 42. Resample nonpositive factors. Mark every row SIMULATED.
3. Validate schema, finite numeric values, material compatibility, provenance and physical limits. Blank values never become zero. Report all rejected/excluded rows. Block training outside the configured domain. Maintain separate origins.
4. Train Linear Regression and a modest Random Forest (120 trees, minimum leaf size 2, seed 42). Raw numeric inputs need no scaling for these implementations. Randomly split simulated rows 80/20. Compute MAE, RMSE and R² on held-out rows only.
5. Separately fit fresh estimators to Vf < 55% and evaluate Vf ≥ 55%. This is an extrapolation stress test, not the metric used for model selection. Publish both results. An unavailable split is reported as unavailable, never assigned a fabricated score.
6. Save the random-split estimator with the lowest held-out RMSE. Do not assume Random Forest wins. Retain the holdout rather than refitting all data. This selection set is not a pristine final benchmark; repeated tuning against it can bias performance estimates.
7. Record data/parameter/model hashes, exact parameter snapshot, source origin, features and units, version, UTC timestamp, sample counts, filtering rules, library version, metrics and held-out predictions.
8. Predict only inside the saved supported domain. Warn within 5% of any boundary. Block nonphysical negative/nonfinite model outputs. Edge warnings do not measure uncertainty; being inside a rectangular domain does not guarantee local sample coverage.
9. Compare literature measurements separately with deterministic simulator and surrogate estimates, showing eligible n and per-study metrics. Exclude unsupported architecture and out-of-domain rows, explicitly reporting them. Never add these rows to training.

Experimental uploads are a separate optional workflow using EXPERIMENTAL_UPLOAD and nonblank study_id. GroupShuffleSplit holds out whole studies (20% of groups, not necessarily 20% of rows). At least two studies and ten accepted rows are required by the implementation; fewer than 30 rows warn that generalisation cannot be established. A single study is blocked. The supported experimental-model domain uses training-set feature minima/maxima, within the configured physical domain. The upload's study split is recorded for audit. Architecture and test-condition compatibility still require human scientific review.

MAE is average absolute error in MPa; RMSE gives extra weight to large errors in MPa; R² is relative improvement over predicting the test mean and can be negative. R² is undefined for fewer than two points or constant targets and is displayed as null. No training scores are presented as test scores. Software fixtures that imitate literature schemas are explicitly test-only and are never exported as literature evidence.
